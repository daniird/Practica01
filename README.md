# Practica01
Este proyecto web para la Práctica 01 de TIC II (Salesianos Coruña) presenta y compara tres grados universitarios tecnológicos en A Coruña: Inteligencia Artificial, Ingeniería Informática y Ciencia e Ingeniería de Datos. El sitio se organiza
en tres páginas (index.html, opciones.html y salidas.html) que muestran un resumen general de cada carrera, una comparativa de sus competencias y ventajas, y sus principales salidas profesionales. Para su desarrollo se ha utilizado HTML en la
estructura, CSS (Estilos.css) para el diseño personalizado y Bootstrap 5.3.8 para la maquetación y los componentes interactivos como tarjetas, tablas, desplegables, pestañas y el carrusel de imágenes.
